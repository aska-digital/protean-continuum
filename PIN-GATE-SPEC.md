# PIN Gate Specification (static Pages export)

This export is a **synthetic demonstration snapshot**. The access gate is honest
friction, not confidentiality: GitHub Pages serves every file in the branch to
anyone who can name the URL (architecture D0), and the board data here is
generated test data only. The gate keeps casual readers on the entry screen;
it is a lock on a poster, and it is documented as such.

## What is verified

`pin-check.js` (the only board script in `index.html`, a classic blocking script in
`<head>`) computes the SHA-256 digest of the entered code's **exact UTF-8 bytes** —
no trailing newline, no padding — and compares it to its `PIN_HASH_HEX` constant.
The plaintext code exists nowhere in this repository by construction; only the
hex digest does, and only inside `pin-check.js`.

## Session and backoff contract

- First successful check writes `sessionStorage["continuum-unlocked"] = "1"`.
  The key is per-tab and per-origin: a new tab re-prompts; a cleared session is
  indistinguishable from a first visit.
- Wrong attempts are counted client-side only. Nothing is logged or sent anywhere.
- Bounded linear backoff: attempts 1–3 free, then a 5 s, 10 s, 20 s, 40 s wait
  (40 s cap). The counter resets on success or after 60 s without attempts.
  Waits render as a whole-second countdown; the region re-announces only the start
  and the ready message.

## Re-hashing (owner PIN swap)

Canonical hash input — `echo` is **forbidden** (it appends a newline and silently
mismatches):

```sh
printf '%s' '<THE-CODE>' | shasum -a 256 | awk '{print $1}'
```

1. Compute the new 64-lowercase-hex digest with the command above.
2. Replace the single constant:
   `sed -i '' 's/PIN_HASH_HEX = .*/PIN_HASH_HEX = "<new-hex>";/' pin-check.js`
3. Commit and push the `gh-pages` branch (one file, one line changed).
4. Verify: `grep -c 'PIN_HASH_HEX' pin-check.js` → 1, and confirm the plaintext
   code appears in no file: `git grep <the-code>` → zero hits.

Never paste the plaintext into an issue, PR, commit message, or document.

## Build provenance

The entire export tree is regenerated by `tools/build_static_snapshot.py` on the
project's default branch, from synthetic fixtures only. `manifest.sha256` carries
the digest of every file in the tree except itself.
